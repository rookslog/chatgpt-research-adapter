# Project overlay: chatgpt-research-adapter

This overlay is narrower than the global routing table. Explicit owner
declarations still win.

## Provisional Terra X-High investigation trial

| Field | Project rule |
| --- | --- |
| Scope | The next three comparable broad, substantive M007/M008 repository or capability investigations |
| Route | `gpt-5.6-terra` at `xhigh` |
| Surface | A per-call surface that attests both model and effort; for native Codex delegation, set `model=gpt-5.6-terra`, `reasoning_effort=xhigh`, and use a bounded context packet |
| Basis | Explicit owner declaration on 2026-08-30; the owner wants higher-thoroughness observations that can be compared with prior Terra High runs |
| Required oracle | Exact source/test references, root verification of load-bearing claims, and the ticket's declared deterministic or research-evidence checks |
| Trial record | Route-planned and disposition events plus the project issue/artifact locator; record only directly observed usage and interventions |
| Review point | After three comparable runs; summarize validation, rework, interventions, usage when observable, and confounders without claiming causal superiority |
| Immediate rollback trigger | Scope or write-boundary violation, unavailable required tool, or repeated unsupported load-bearing claims |

## Non-applicability

Do not use this trial as a blanket route for fixed transformations,
deterministic commands, mechanical edits, tightly bounded implementation with a
direct oracle, browser-control work needing another surface, or independent
high-consequence review. Triage those tasks by their actual shape and state the
exception before launch.

Sol is an independent advice/review channel for consequential ambiguity or a
weak oracle; it is not an authority tier. Root remains responsible for
integration and final verification.
